# American Forgotten Outlaws — Cloud AI Video Studio

A cloud-based AI video production project for creating cinematic 10–12 minute historical documentaries about forgotten American outlaws using Remotion, Three.js, AI narration, historical visuals, sound effects, and automated video rendering.

## Project Configuration
- **Channel Name:** American Forgotten Outlaws
- **Aspect Ratio:** 16:9 (1920x1080)
- **Frame Rate:** 30 FPS
- **Visual Style:** 1870s Gritty Historical Western Documentary
- **Pilot Episode:** John Wesley Hardin (1-Minute Test Render)

## Folder & File Structure
- `package.json` — Remotion & Three.js dependencies
- `src/script.json` — Automated scene breakdown, prompts & narration
- `src/Video.tsx` — 16:9 video composition & caption styling
- `.github/workflows/render.yml` — Cloud rendering automation
